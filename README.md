# Coleção de Jogos em Terminal (C++)

Este projeto reúne uma coleção de jogos interativos desenvolvidos para serem executados diretamente no console (Windows).

## 📂 Estrutura e Navegação

Cada jogo da coleção está organizado em seu próprio diretório contendo o código-fonte correspondente e uma **documentação individual (`README.md`)**.

Nos arquivos `README.md` específicos de cada jogo, você encontrará:

* Descrição detalhada do projeto e objetivo do jogo.

* Regras e condições de vitória / derrota.

* Mecânicas específicas e fórmulas de pontuação.

* Mapeamento completo dos controles de entrada.

## 🎮 Jogos Disponíveis

### 1. [DatilografarHero](./DatilografarHero/)

Jogo de agilidade e ritmo para terminal inspirado em jogos musicais. Teste seus reflexos e velocidade de digitação acertando as letras em queda no momento exato em que atingem a linha de marcação.

### 2. [SnakeGame](./SnakeGame/)

Adaptação do clássico jogo da cobrinha. Navegue pelo cenário, colete maçãs para somar pontos e evite colidir com as paredes e os obstáculos gerados aleatoriamente pelo mapa.

### 3. [TheMazeGame](./TheMazeGame/)

Jogo de navegação e estratégia em um labirinto. Encontre a saída antes que sua pontuação acabe, sabendo que cada segundo transcorrido e cada movimento realizado consomem pontos.

## Como Executar um Jogo

Para executar qualquer um dos jogos, basta abrir o seu arquivo `.exe` correspondente contido dentro de cada pasta.
